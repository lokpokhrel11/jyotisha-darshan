# Source map: Chapter 4.3
Primary study notes PDF, pp.25–28: local sunrise method, istakala formula, previous-day sunrise for pre-sunrise birth; Damouli 2083 Asar 4, birth 13:00, rounded local sunrise 05:14, result 19 ghadi 25 pala.
The notes also describe Kathmandu panchanga sunrise, 4-minute reference correction, birthplace time adjustment, and seconds rounding. This release does not calculate those corrections; it requires a correctly adjusted local sunrise input. The previous-day handling is an educational extension of the stated rule, not a full date-aware calendar engine.
