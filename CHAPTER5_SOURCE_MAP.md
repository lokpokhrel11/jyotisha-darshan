# Chapter 5 source map
Primary source: 117-page Jyotisha study notes, October 2026, PDF pp. 43–47, sections 5.1–5.3.
Case ka: istakala > E; bhayata = istakala − E; bhabhoga = 60 − E + next-day end.
Case kha: istakala < E; bhayata = 60 − previous-day preceding nakshatra end + istakala; bhabhoga = 60 − preceding end + E.
This lesson deliberately excludes equality, kshaya, vriddhi and automated nakshatra identification.
