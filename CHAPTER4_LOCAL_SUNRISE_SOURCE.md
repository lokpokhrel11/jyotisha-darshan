# Chapter 4 local sunrise source map
Primary: 117-page Jyotisha study notes, October 2026, PDF pp.25–28, sections 4.3 and 4.3 क.
- Calendar sunrise − 4 minutes for reference meridian; signed birthplace offset.
- East positive, west negative, seconds >=30 rounded up to a minute.
- Damouli: 05:10, offset −07:52 => rounded −8 minutes, sunrise 05:14.
- Alternate seconds-level route: −03:44 + 07:52 = +04:08, rounded to 05:14.
The calculation is a teaching convention sourced to these notes; not an astronomical sunrise engine.
